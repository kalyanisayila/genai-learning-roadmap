# Week 3 - Day 20: Prompt Chaining

## What is Prompt Chaining?

Prompt chaining is the process of breaking a complex task into multiple smaller prompts. The output of one prompt becomes the input for the next prompt.

## Why Use Prompt Chaining?

- Improves accuracy
- Handles complex tasks efficiently
- Makes responses easier to understand
- Reduces errors

## Example

### Prompt 1
Summarize the following article in 100 words.

### Output
A short summary of the article.

### Prompt 2
Using the above summary, list the three main points.

### Output
1. Main Point One
2. Main Point Two
3. Main Point Three

## Applications

- Content creation
- Data analysis
- Report generation
- Coding assistance
- Customer support

## Advantages

- Better organization
- More reliable results
- Easier debugging
- Improved AI performance

## Key Takeaways

- Break large tasks into smaller prompts.
- Use the output of one prompt as the input for the next.
- Prompt chaining improves the quality of AI responses.

## Conclusion

Prompt chaining is an effective prompt engineering technique for solving complex problems step by step while maintaining accuracy and clarity.
