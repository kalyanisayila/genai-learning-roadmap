# Day 21 – AI Agents

## What is an AI Agent?

An AI Agent is an intelligent system that can understand goals, make decisions, use tools, and perform tasks automatically.

Unlike a chatbot, an AI agent can perform actions instead of only answering questions.

## Components of an AI Agent

- Goal
- LLM (Brain)
- Memory
- Tools
- Actions


## How AI Agents Work

1. Receive a task
2. Understand the request
3. Plan the steps
4. Select tools
5. Execute actions
6. Review the results
7. Return the final output

## Example

User:
> Find Python internships in Bangalore.

The AI Agent:
- Searches the web
- Filters internships
- Summarizes the top opportunities
- Displays the result

## Advantages

- Saves time
- Automates tasks
- Works with multiple tools
- Improves productivity


## Limitations

- Can make mistakes
- Requires good instructions
- Depends on available tools


## Interview Questions

**1. What is an AI Agent?**

An AI Agent is an intelligent system that can understand goals, use tools, and perform tasks automatically.

**2. Difference between AI Agent and Chatbot?**

A chatbot mainly answers questions, while an AI Agent can plan and execute actions.

**3. What are the main components of an AI Agent?**

Goal, LLM, Memory, Tools, and Actions.

## Key Takeaways

- AI Agents perform actions.
- LLMs provide reasoning.
- Tools enable real-world tasks.
- Memory helps maintain context.
